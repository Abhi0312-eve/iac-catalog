# Changelog

All notable changes to the AWS EC2 Terraform implementation are documented here.

## 1.0.0 — Initial Internal Release

### Added

- AWS EC2 provisioning through the Backstage AWS EC2 template
- AWS region selection
- EC2 instance type selection
- Operating system / AMI selection
- Instance name configuration
- Owner tagging
- Terraform project generation
- GitHub repository publishing
- GitHub Actions workflow integration
- Terraform outputs for:
  - Instance ID
  - Public IP
  - Private IP
  - AWS region
